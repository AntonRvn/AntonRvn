### Обо мне

Привет! Я — системный аналитик с широким IT-кругозором и навыками в DS, ML, BI.

Я перевожу бизнес-потребности в технические решения, провожу проект от этапа сбора требований и прототипирования в Figma до разработки OpenAPI-спецификации, интеграционных схем и ТЗ.

**Основные задачи, интересующие меня сейчас:**
- Проектирование REST API и интеграционных решений (OpenAPI, Swagger, Postman).
- Моделирование бизнес-процессов и архитектуры микросервисов (BPMN, UML).
- Построение ETL/ELT-пайплайнов и витрин данных (DWH).
- Применение ML для обогащения аналитики и автоматизации решений.
